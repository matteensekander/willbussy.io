# 🐍 willbussy.io

A browser-based multiplayer-style snake game inspired by slither.io.

## [▶ PLAY NOW](https://matteensekander.github.io/willbussy.io/)

---

## Controls

| Key | Action |
|-----|--------|
| `W A S D` / Arrow Keys | Move |
| `Space` | Boost (shrinks your snake) |
| `Shift` | Dash — unlocks at length 50 |

## Features

- 8 unlockable skins: Neon, Fire, Galaxy, Ocean, Venom, Ice, Gold, Shadow
- 3 power-ups: ⚡ Speed Boost, 👻 Ghost Mode, 🧲 Magnet
- Kill streak system — **SLURPED! 🐍**
- Day / Night cycle
- Persistent high score leaderboard
- Minimap + live leaderboard HUD
- 6 AI opponents always active
